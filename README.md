# README

**Tech Stack**
-Ruby on Rails
-Postgresql
-Tailwind CSS
**Installation**
-git clone <githubrepo>
**How to run**
-should have a ruby and rails install + postgres
-run the server via command "bin/dev"
**Design Decisions**
-Modular Structure: The code is structured to allow easy extension (e.g., adding new discount rules).
-Scalability: The logic can be expanded to support multiple marketplaces and pricing models.
-User-Friendly UI: If implemented in React, the interface is simple and intuitive.
